# Student Grade Management System

This is a simple Student Grade Management System created using HTML, CSS and JavaScript.

## Features

- Add student details
- Enter marks for different subjects
- Calculate total marks
- Calculate average marks
- Find highest and weakest marks
- Assign grades based on average
- Display student data in a table
- Delete student records
- Store student data using browser Local Storage
- View previously stored student data

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## Recent Update

The project has been updated to store student data using Local Storage. The stored data remains available even after refreshing or reopening the webpage in the same browser.

A `View Stored Data` button has also been added to display the saved student records separately.

## How It Works

1. Enter the student's details and marks.
2. Click `Add Student`.
3. The student details and calculated results are displayed in the table.
4. Click `Store Data` to save the records in the browser.
5. Click `View Stored Data` to view the saved records.

## Note

The current version uses browser Local Storage for data persistence. A backend database can be added as a future improvement.
